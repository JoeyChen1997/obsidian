# Paperlist 精读台账与研究流程

编目和精读分别记账。47,568 是本地 PDF 文件数，含可能的重复版本和非研究条目；不能把这个数字当作独立论文数，或把已索引当作已读。此台账只记实际发生的阅读，不自动把摘要或命中结果升级为精读。

## 持久记忆和免重复规则

- **唯一工作记录**：每篇已核作品必须有一个图谱节点和一张文献卡；图谱的 `reading_status`、`reading_note`、`sections` 与卡片一起构成持久阅读记忆。下一批先查这些字段，不重新打开 `core_read` 作品。卡片中的“未核范围／补件缺口”是停点，不是下次从第一页重读的理由。
- **来源与作品分开**：来源级覆盖清单仍保留每个 PDF 的 ID。重刊、勘误、工作稿和同题名候选只有在身份核查时再打开；已读作品的其他版本不会继承正文已核状态，核查后写入 `verified_variants` 或 `source_gap`，避免把版次误计为新论文。
- **续读顺序**：队列只取 `not_reviewed`／`queued`；`core_read` 只进入第二轮横向比较或补件回查，除非用户明确要求重读。每次停点要写物理 PDF 页范围、已核段落、独立复算和下次首个页码；因此跨对话续跑不依赖记忆中的临时文本。
- **三种完成状态**：`core_read` = 主文核心内容已读并留卡；`screened` = 只读局部，不可用于定稿；`source_gap` = 身份或原件／关键材料未足，保留已查证据。只有 `core_read` 或明确 `not_applicable` 才从逐篇主队列退出。

## 状态和证据标准

- `queued`：已确认原件或可追踪的候选来源。`screened`：看过首页或局部正文，只做相关性判断。
- `core_read`：实读正文、研究结果及 PDF 中与核心结论相关的证明、估计或验证材料；独立附录、复现和未核公式单列。并不意味着独立重证每个结果。
- `source_gap`：缺原件、附录、正文不可读或版本冲突；记录缺口和已查路线，不补写未见内容。不同版本在引文核对后合并为同一论文记录，保留各段实际所据版本。
- `not_applicable`（仅用于来源）表示据原页确认是非研究材料；保留 PDF、类别和证据页，但不计入独立作品、精读或未裁决来源。尚未核的索引样题名仍是候选，不自动排除。
- 每条关系写出方向与类型（引入组件 / 直接扩展 / 对照或反例 / 实证对应 / 仅引用 / 机制相似但未发现直接引用）、改变的假设、结果变化和**原文证据位置**。参考文献命中不等于继承模型。
- 每个重要结论区分**作者结果、可核复算、综合解读、待验证想法**。Theory 卡核对参与者、策略、信息、时序、均衡、获利偏离和参数边界；实证或结构论文另记录数据、识别/估计、反事实及机制证据，不强套博弈模板。用 [[Marketing Paper/Theory 文献卡模板|Theory 文献卡模板]] 起稿。

## 回答新研究问题时

1. 把问题拆成**商业情境、模型原语和预测**。如「平台限制定向」还要拆成哪一层的约束、谁观察数据、广告费是否内生，以及受影响的是企业利润还是消费者福利。
2. 从已有的主题谱系和已读卡起步，同时查全库的题名、正文、术语变体和邻近期刊。向后追引用的模型和证明，向前用作者、题名或 DOI 找后续正文引用；检查不引用同一前驱、但使用同一机制的工作。相关结果不能只靠一次关键词命中。
3. 整理基准、分支、反转和最新变体，逐列对齐假设与可比的结果；列出高度相关论文、外围证据和还没解决的覆盖盲区。要说「所有相关」，先说明检索的库、期刊、年份与外部来源边界；不要从本地未命中推出没有先例。
4. 把新读的论文、可核实的关系和证据追加到图谱或台账，把暂时未解决的问题留在队列。后续阅读按研究问题成组推进；覆盖目标仍是逐篇，不因为某篇没进第一组就标作已审读或排除。
