# 151 交易策略 — 第2章：期权策略

> 本章涵盖 57 个期权交易策略，从基础的备兑开仓到复杂的蝴蝶/秃鹰组合。

## 期权基础概念

**期权**是一种金融衍生品合约，赋予持有人在特定时间以约定价格买入或卖出标的资产的**权利**（非义务）。

| 术语 | 含义 |
|------|------|
| **行权价 $K$** | 合约约定的买卖价格 |
| **到期日 $T$** | 期权到期时间 |
| **权利金** | 买方支付给卖方的费用 |
| **ATM** | 平值（At-The-Money），当前价格 $\approx$ 行权价 |
| **ITM** | 实值（In-The-Money），期权有内在价值 |
| **OTM** | 虚值（Out-of-The-Money），期权无内在价值 |
| **TTM** | 到期剩余时间（Time-To-Maturity） |

**欧式看涨期权**收益：$f_{call} = \max(S_T - K,\ 0)$
**欧式看跌期权**收益：$f_{put} = \max(K - S_T,\ 0)$

### 策略分类

```
期权策略
├── 方向性策略
│   ├── 看涨策略（股价上涨获利）
│   └── 看跌策略（股价下跌获利）
└── 非方向性策略
    ├── 波动率策略（股价大幅波动获利）
    └── 横盘策略（股价稳定获利）
```

### 符号约定
- $f_T$：到期收益
- $S_0$：建仓时股价
- $S_T$：到期时股价
- $C$：净收到的权利金（净信用）
- $D$：净支付的权利金（净借方）
- $H = D$（净借方交易）或 $H = -C$（净信用交易）
- $S^*$：盈亏平衡点
- $P_{max}$：最大利润
- $L_{max}$：最大亏损

---

## 策略 2.2：备兑看涨（Covered Call）

**别名**：买入-写出策略（Buy-Write）
**操作**：持有股票 + 卖出看涨期权（行权价 $K$）
**市场观点**：中性偏看涨

> 相当于卖出裸看跌期权的收益结构。可通过定期卖出 OTM 看涨期权来持续产生收入。

| 指标 | 公式 |
|------|------|
| 到期收益 | $f = K - S_0 - (K - S_T)^+ + C$ |
| 盈亏平衡 | $S^* = S_0 - C$ |
| 最大利润 | $P_{max} = K - S_0 + C$ |
| 最大亏损 | $L_{max} = S_0 - C$ |

---

## 策略 2.3：备兑看跌（Covered Put）

**别名**：卖出-写出策略（Sell-Write）
**操作**：做空股票 + 卖出看跌期权（行权价 $K$）
**市场观点**：中性偏看跌

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = S_0 + C$ |
| 最大利润 | $P_{max} = S_0 - K + C$ |
| 最大亏损 | $L_{max} = \infty$ |

---

## 策略 2.4：保护性看跌（Protective Put）

**别名**：婚姻看跌（Married Put）/ 合成看涨
**操作**：持有股票 + 买入 ATM/OTM 看跌期权（$K \leq S_0$）
**市场观点**：看涨（对冲下行风险）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = S_0 + D$ |
| 最大利润 | $P_{max} = \infty$ |
| 最大亏损 | $L_{max} = S_0 - K + D$ |

---

## 策略 2.5：保护性看涨（Protective Call）

**别名**：婚姻看涨 / 合成看跌
**操作**：做空股票 + 买入 ATM/OTM 看涨期权（$K \geq S_0$）
**市场观点**：看跌（对冲上行风险）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = S_0 - D$ |
| 最大利润 | $P_{max} = S_0 - D$ |
| 最大亏损 | $L_{max} = K - S_0 + D$ |

---

## 策略 2.6：牛市看涨价差（Bull Call Spread）

**操作**：买入近 ATM 看涨（$K_1$）+ 卖出 OTM 看涨（$K_2$），$K_1 < K_2$
**市场观点**：看涨（净借方，资本利得策略）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = K_1 + D$ |
| 最大利润 | $P_{max} = K_2 - K_1 - D$ |
| 最大亏损 | $L_{max} = D$ |

---

## 策略 2.7：牛市看跌价差（Bull Put Spread）

**操作**：买入 OTM 看跌（$K_1$）+ 卖出 OTM 看跌（$K_2$），$K_1 < K_2$
**市场观点**：看涨（净信用，收入策略）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = K_2 - C$ |
| 最大利润 | $P_{max} = C$ |
| 最大亏损 | $L_{max} = K_2 - K_1 - C$ |

---

## 策略 2.8：熊市看涨价差（Bear Call Spread）

**操作**：买入 OTM 看涨（$K_1$）+ 卖出 OTM 看涨（$K_2$），$K_1 > K_2$
**市场观点**：看跌（净信用，收入策略）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = K_2 + C$ |
| 最大利润 | $P_{max} = C$ |
| 最大亏损 | $L_{max} = K_1 - K_2 - C$ |

---

## 策略 2.9：熊市看跌价差（Bear Put Spread）

**操作**：买入近 ATM 看跌（$K_1$）+ 卖出 OTM 看跌（$K_2$），$K_1 > K_2$
**市场观点**：看跌（净借方，资本利得策略）

| 指标 | 公式 |
|------|------|
| 盈亏平衡 | $S^* = K_1 - D$ |
| 最大利润 | $P_{max} = K_1 - K_2 - D$ |
| 最大亏损 | $L_{max} = D$ |

---

## 策略 2.10：多头合成远期（Long Synthetic Forward）

**操作**：买入 ATM 看涨（$K = S_0$）+ 卖出 ATM 看跌（$K = S_0$）
**市场观点**：看涨（模拟多头股票/期货头寸）

| 指标 | 公式 |
|------|------|
| 到期收益 | $f = S_T - K - H$ |
| 盈亏平衡 | $S^* = K + H$ |
| 最大利润 | $P_{max} = \infty$ |
| 最大亏损 | $L_{max} = K + H$ |

---

## 策略 2.11：空头合成远期（Short Synthetic Forward）

**操作**：买入 ATM 看跌 + 卖出 ATM 看涨（$K = S_0$）
**市场观点**：看跌（模拟空头股票/期货头寸）

---

## 策略 2.12：多头组合（Long Combo / Long Risk Reversal）

**操作**：买入 OTM 看涨（$K_1$）+ 卖出 OTM 看跌（$K_2$），$K_1 > K_2$
**市场观点**：看涨（资本利得策略）

---

## 策略 2.13：空头组合（Short Combo / Short Risk Reversal）

**操作**：买入 OTM 看跌（$K_1$）+ 卖出 OTM 看涨（$K_2$），$K_2 > K_1$
**市场观点**：看跌

---

## 策略 2.14：牛市看涨阶梯（Bull Call Ladder）

**操作**：买入近 ATM 看涨（$K_1$）+ 卖出 OTM 看涨（$K_2$）+ 卖出更高 OTM 看涨（$K_3$）
**市场观点**：保守看涨或非方向性（低波动率预期）

> 相当于牛市看涨价差 + 卖出额外 OTM 看涨（融资）

---

## 策略 2.15：牛市看跌阶梯（Bull Put Ladder）

**操作**：卖出近 ATM 看跌（$K_1$）+ 买入 OTM 看跌（$K_2$）+ 买入更低 OTM 看跌（$K_3$）
**市场观点**：通常由牛市看跌价差演变而来（股价下跌时调整为看跌）

---

## 策略 2.16：熊市看涨阶梯（Bear Call Ladder）

**操作**：卖出近 ATM 看涨（$K_1$）+ 买入 OTM 看涨（$K_2$）+ 买入更高 OTM 看涨（$K_3$）
**市场观点**：通常由熊市看涨价差演变而来（股价上涨时调整）

---

## 策略 2.17：熊市看跌阶梯（Bear Put Ladder）

**操作**：买入近 ATM 看跌（$K_1$）+ 卖出 OTM 看跌（$K_2$）+ 卖出更低 OTM 看跌（$K_3$）
**市场观点**：保守看跌或非方向性

---

## 策略 2.18：日历看涨价差（Calendar Call Spread）

**操作**：卖出近月看涨 + 买入远月看涨（相同行权价）
**市场观点**：中性（利用时间价值衰减）

---

## 策略 2.19：日历看跌价差（Calendar Put Spread）

**操作**：卖出近月看跌 + 买入远月看跌（相同行权价）
**市场观点**：中性

---

## 策略 2.20-2.21：对角价差（Diagonal Spread）

**操作**：不同到期日 + 不同行权价的期权组合
- **对角看涨价差**：卖出近月 OTM 看涨 + 买入远月 ATM 看涨
- **对角看跌价差**：卖出近月 OTM 看跌 + 买入远月 ATM 看跌

---

## 策略 2.22：多头跨式（Long Straddle）

**操作**：买入 ATM 看涨 + 买入 ATM 看跌（相同行权价 $K$）
**市场观点**：波动率策略（预期大幅波动，方向不确定）

| 指标 | 公式 |
|------|------|
| 上方盈亏平衡 | $S^*_{up} = K + D$ |
| 下方盈亏平衡 | $S^*_{down} = K - D$ |
| 最大利润 | $P_{max} = \infty$ |
| 最大亏损 | $L_{max} = D$（股价恰好等于 $K$ 时） |

---

## 策略 2.23：多头宽跨式（Long Strangle）

**操作**：买入 OTM 看涨（$K_1$）+ 买入 OTM 看跌（$K_2$），$K_1 > K_2$
**市场观点**：波动率策略（比跨式便宜，但需要更大波动才能盈利）

---

## 策略 2.24：多头内跨式（Long Guts）

**操作**：买入 ITM 看涨 + 买入 ITM 看跌
**市场观点**：波动率策略（比跨式贵）

---

## 策略 2.25：空头跨式（Short Straddle）

**操作**：卖出 ATM 看涨 + 卖出 ATM 看跌
**市场观点**：横盘策略（预期低波动率，收取权利金）
**风险**：最大亏损无限

---

## 策略 2.26：空头宽跨式（Short Strangle）

**操作**：卖出 OTM 看涨 + 卖出 OTM 看跌
**市场观点**：横盘策略（比空头跨式安全区间更宽）

---

## 策略 2.27：空头内跨式（Short Guts）

**操作**：卖出 ITM 看涨 + 卖出 ITM 看跌
**市场观点**：横盘策略

---

## 策略 2.28-2.31：合成跨式（Synthetic Straddle）

- **多头看涨合成跨式**：买入 2 个 ATM 看涨 + 做空 1 股股票
- **多头看跌合成跨式**：买入 2 个 ATM 看跌 + 持有 1 股股票
- **空头看涨合成跨式**：卖出 2 个 ATM 看涨 + 持有 1 股股票
- **空头看跌合成跨式**：卖出 2 个 ATM 看跌 + 做空 1 股股票

---

## 策略 2.32-2.33：备兑空头跨式/宽跨式

- **备兑空头跨式**：持有股票 + 卖出 ATM 看涨 + 卖出 ATM 看跌
- **备兑空头宽跨式**：持有股票 + 卖出 OTM 看涨 + 卖出 OTM 看跌

---

## 策略 2.34：Strap

**操作**：买入 2 个 ATM 看涨 + 买入 1 个 ATM 看跌
**市场观点**：偏看涨的波动率策略

---

## 策略 2.35：Strip

**操作**：买入 1 个 ATM 看涨 + 买入 2 个 ATM 看跌
**市场观点**：偏看跌的波动率策略

---

## 策略 2.36-2.39：比率价差（Ratio Spread）

- **看涨比率反向价差**：买入 2 个 OTM 看涨 + 卖出 1 个 ATM 看涨（看涨 + 高波动率）
- **看跌比率反向价差**：买入 2 个 OTM 看跌 + 卖出 1 个 ATM 看跌（看跌 + 高波动率）
- **看涨比率价差**：买入 1 个 ATM 看涨 + 卖出 2 个 OTM 看涨（中性偏看涨，低波动率）
- **看跌比率价差**：买入 1 个 ATM 看跌 + 卖出 2 个 OTM 看跌（中性偏看跌，低波动率）

---

## 策略 2.40-2.43：蝴蝶价差（Butterfly Spread）

### 多头看涨蝴蝶（Long Call Butterfly）
**操作**：买入 1 个低行权价看涨（$K_1$）+ 卖出 2 个中间行权价看涨（$K_2$）+ 买入 1 个高行权价看涨（$K_3$）
**市场观点**：横盘（预期股价在 $K_2$ 附近）

| 指标 | 说明 |
|------|------|
| 最大利润 | 股价 $= K_2$ 时 |
| 最大亏损 | 净借方 $D$ |

- **变形看涨蝴蝶**：行权价不对称
- **多头看跌蝴蝶**：用看跌期权构建
- **空头看涨/看跌蝴蝶**：反向操作，波动率策略

---

## 策略 2.44-2.45：铁蝴蝶（Iron Butterfly）

### 多头铁蝴蝶（Long Iron Butterfly）
**操作**：买入 OTM 看跌（$K_1$）+ 卖出 ATM 看跌（$K_2$）+ 卖出 ATM 看涨（$K_2$）+ 买入 OTM 看涨（$K_3$）
**市场观点**：横盘（净信用，收入策略）

### 空头铁蝴蝶（Short Iron Butterfly）
**市场观点**：波动率策略（净借方）

---

## 策略 2.46-2.51：秃鹰价差（Condor Spread）

与蝴蝶类似，但中间两个行权价不同（$K_2 \neq K_3$），盈利区间更宽：

- **多头/空头看涨秃鹰**
- **多头/空头看跌秃鹰**
- **多头铁秃鹰**：买入 OTM 看跌 + 卖出较高 OTM 看跌 + 卖出较低 OTM 看涨 + 买入 OTM 看涨（横盘，净信用）
- **空头铁秃鹰**：反向（波动率策略）

---

## 策略 2.52：多头盒式（Long Box）

**操作**：牛市看涨价差 + 熊市看跌价差（相同行权价）
**特点**：无风险套利，到期收益固定为 $K_2 - K_1$，用于锁定无风险利率

---

## 策略 2.53：领口（Collar）

**操作**：持有股票 + 买入 OTM 看跌（$K_1$）+ 卖出 OTM 看涨（$K_2$），$K_1 < S_0 < K_2$
**市场观点**：中性（限制上下行风险，低成本对冲）

---

## 策略 2.54-2.57：海鸥价差（Seagull Spread）

四种变体（看涨/看跌 × 多头/空头），通过三腿期权组合实现低成本方向性策略：

- **看涨空头海鸥**：卖出 OTM 看跌 + 买入 ATM 看涨 + 卖出 OTM 看涨（看涨，低成本）
- **看跌多头海鸥**：买入 ATM 看跌 + 卖出 OTM 看跌 + 卖出 OTM 看涨（看跌，低成本）
- **看跌空头海鸥**：卖出 OTM 看涨 + 买入 ATM 看跌 + 卖出 OTM 看跌
- **看涨多头海鸥**：买入 ATM 看涨 + 卖出 OTM 看涨 + 卖出 OTM 看跌
