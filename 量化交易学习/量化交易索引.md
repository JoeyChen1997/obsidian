## 🔑 核心概念速查

### 策略类型
| 类型 | 逻辑 | 代表策略 |
|------|------|---------|
| **动量（Momentum）** | 趋势延续 | 价格动量、趋势跟踪 |
| **均值回归（Mean-Reversion）** | 价格回归均值 | 配对交易、IBS 均值回归 |
| **套利（Arbitrage）** | 无风险价差 | 现货-期货套利、三角套利 |
| **套息（Carry）** | 持有收益 | 外汇套息、债券套息 |
| **价值（Value）** | 低估资产 | 股票价值、大宗商品价值 |
| **波动率（Volatility）** | 波动率定价偏差 | VRP、可转债套利 |

### 风险管理
| 概念 | 说明 |
|------|------|
| **美元中性** | 多空头寸金额相等，消除市场方向风险 |
| **久期中性** | 多空头寸久期相等，消除利率风险 |
| **Delta 对冲** | 动态调整股票头寸，消除期权的方向风险 |
| **波动率目标** | 根据波动率动态调整仓位大小 |
| **风险平价** | 使各资产对组合风险贡献相等 |
